Le nouveau nom n’est pas perdu par hasard : 
vers la ligne 6696 de index.html, un petit script efface volontairement le nom mémorisé à chaque chargement de la page. 

Ce script ne suffit pas à supprimer seul : il cachait un second problème. 
L’animation de frappe écrit le nom lettre par lettre (« L », « Lu », « Luc »…) et chaque étape était mémorisée. 

Si on fermait la page pendant l’animation, le nom restait tronqué. 
Je l’ai vérifié sur votre fichier d’origine : à mi-animation, il avait mémorisé « Lucas ».

Il faut donc deux modifications dans index.html. Je vous envoie aussi le fichier avec ces deux corrections déjà faites.

1. Supprimer entièrement ce bloc (vers la ligne 6696)

<!-- Réinitialisation du nom par défaut à chaque rechargement -->
<!-- Un mini-script de réinitialisation. -->
<script>
/* Le petit script qui remet le nom par défaut à chaque rechargement : il efface le nom personnalisé mémorisé. try/catch évite une erreur si le navigateur bloque le localStorage. */
try { localStorage.removeItem('portfolio_custom_name'); } catch(e) {}
/* La ligne suivante referme ce script. */
</script>


2. Dans la fonction setupWatchers() (vers la ligne 6930), remplacer :

      new MutationObserver(function () {

        setTimeout(function () { onNameChanged(heroEl); }, 0);

par :

      new MutationObserver(function () {
        /* L'animation de frappe écrit le nom lettre par lettre (« L », « Lu », « Luc »…) : on ne mémorise QUE ce que vous tapez vous-même en mode édition. */
